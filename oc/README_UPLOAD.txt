OVARIAN CANCER PATIENT VOICE WEBSITE
GitHub Pages upload package

【このZIPの使い方】
1. ZIPを展開してください。
2. 展開したフォルダの中にあるファイルを、すべてGitHubリポジトリのルートへアップロードしてください。
   ※ index.html と画像・CSS・JavaScriptを同じ階層に置く前提です。
3. GitHubの Settings → Pages を開きます。
4. Build and deployment で「Deploy from a branch」を選択します。
5. Branch：main / Folder：/ (root) を選び、Saveします。
6. 数分後に公開URLが発行されます。

【主要ページ】
- index.html        HOME
- diagnosis.html    診断までの道のり
- treatment.html    告知後の治療選択
- impact.html       治療が生活に及ぼす影響
- information.html  患者さんが求めていた情報
- recurrence.html   再発への不安と心の支え
- hints.html        治療に向き合うためのヒント
- about.html        このサイトについて
- 404.html          ページが見つからない場合の画面

【共通ファイル】
- styles.css        デザイン・レスポンシブ表示
- scripts.js        カルーセル、テーマ切替、続きを読む、スマホメニュー
- PNG画像           すべてHTMLと同じ階層から参照

【更新時のポイント】
- 本文を直す場合：該当するHTMLを編集
- 色・余白・文字サイズを直す場合：styles.cssを編集
- カルーセル等の動きを直す場合：scripts.jsを編集

このパッケージはビルド作業不要の静的サイトです。
