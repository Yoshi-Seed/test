# テスト記録 — 凪 1.0.0

作成日：2026-09-08

## 実施済み

### 画面・操作：49チェック

ChromiumのローカルDOMテストで、画面の描画と操作を確認しました。
幅320・375・390・430 CSSピクセルの縦画面を使用しています。

このテスト環境ではURLへのナビゲーションが管理ポリシーで制限されているため、
HTML・CSS・JavaScriptをローカルのテストページへ直接読み込んでいます。
**IndexedDBの読み書き部分はインメモリのテスト用アダプターに差し替えています。**
これは実際のSafariでの永続保存テストでも、HTTPS配信の統合テストでもありません。
製品の `storage.js` は差し替えていません。

確認内容：
- 初期値を捏造しない空画面、強さを選ぶまで保存不可
- 記録、修正、日付をさかのぼった入力、削除
- 「渇望なし」と渇望の記録の区別
- 保存エラー時に入力内容を残してエラーを表示
- 任意の前後の強さ、未記録日を除いた集計
- 相談メモの未保存時・日付不正時の出力停止
- HTMLとして解釈してはいけない入力のエスケープ
- 日数に対応する星、手紙の表示
- 実時刻に基づく休憩タイマー
- テーマ、動きを止める設定、モーダルの上に出るプライバシーカバー
- 各画面・記録フォームの横方向のはみ出し
- 単一記録と全データの削除
- 未処理JavaScriptエラーが発生しないこと

### データ・暗号化・キャッシュ処理：37チェック

Node.jsで製品の `core.js` と暗号化関数を実行しました。
サービスワーカーはVM上の模擬CacheStorageで処理を確認しています。

確認内容：
- データ形式、列挙値、日時整合、ID重複、電話番号形式などの検証
- 日付の月またぎ・うるう日
- 集計の分母、未記録日、0の記録の区別
- バックアップの新旧ID統合
- 実際のWeb Cryptoによる暗号化・復号の往復
- 誤ったパスフレーズ、改変された暗号文、不正な暗号化設定の拒否
- 書き出しごとにsaltとIVが異なること
- オフライン用ファイルの存在、キャッシュ対象の範囲
- 自分の公開範囲に属する旧キャッシュだけを削除すること
- 模擬環境でキャッシュ済みファイルをネットワークなしで返すこと

JavaScriptファイルの構文検査も実施しています。
合計 **86チェックが完了**しています。
これは網羅的な品質保証、実機認証、医療機器評価、第三者セキュリティ監査ではありません。
