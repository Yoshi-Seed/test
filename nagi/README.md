# 凪 — NAGI
### 波と、暮らす。

処方薬への渇望や、そのときの状況を、自分のペースで残すための個人用Webアプリです。
iPhoneの縦画面とホーム画面からの利用を中心に設計しています。

**ビルド不要・アカウント不要・APIキー不要。ZIPを解凍した中身をそのまま公開できます。**
アプリの利用記録や個人情報は、この配布ZIPには含まれていません。

Version 1.0.0 / 2026-09-08

---

## 1. GitHubに置く

新しいリポジトリを1つ用意すると、既存サイトと混ざらずに管理できます。名前は `nagi` などで構いません。

1. ZIPを解凍します。
2. リポジトリの **Add file → Upload files** から、解凍した中のファイルと `assets` フォルダをアップロードしてコミットします。**ZIP自体ではなく、中身をアップロード**してください。
3. リポジトリの **Settings → Pages** を開き、次を指定します。

| 項目 | 設定 |
|---|---|
| Source | Deploy from a branch |
| Branch | main（アップロードしたブランチ） |
| Folder | / (root) |
| 最後の操作 | Save |

`index.html` が公開元の最上位にあり、同じ階層に `app.js`、`style.css` などが並ぶ状態にします。
`assets` はフォルダごと配置してください。隠しファイル `.nojekyll` と `.gitignore` も同梱しています。
Pagesのデプロイ完了後、Settings → Pages に表示される公開URLを開きます。

**アップロードに加え、初回だけPagesの公開設定が必要です。**
GitHub Pagesの利用可否とリポジトリの公開範囲は、GitHubの契約・組織設定に従います。
PagesのWebサイトは、原則としてインターネット上に公開されます。アプリのソースと個人の記録は別です。
記録のバックアップや診察用の書き出しファイルを、このリポジトリに置かないでください。

公式手順：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 2. iPhoneのホーム画面に追加する

iPhoneの通常のSafariで公開URLを開きます。チャット内ブラウザやプライベートブラウズではなく、Safariから操作してください。

**共有 → ホーム画面に追加 →「Webアプリとして開く」をオン → 追加**

Safariのレイアウトによっては、最初に「…」から「共有」を選びます。
追加した「凪」アイコンから起動してください。月と波の専用アイコンを同梱しています。

記録を始める前にホーム画面へ追加し、以後は同じアイコンから開く運用にしてください。
Safariのタブ、プロファイル、別のブラウザ、ホーム画面版など、開く環境を変えた際に記録が共通とは限りません。
引っ越しや機種変更には、アプリのバックアップ／読み込み機能を使います。自動同期はありません。

公式手順：
https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios

## 3. 最初に試すこと

本当の記録をためる前に、テスト用の記録を1件だけ作り、次を確認してください。

- アプリを閉じ、ホーム画面から開き直して記録が残っている。
- 設定のバックアップから `.nagi` ファイルを書き出し、「ファイル」アプリに実際に保存できている。
- そのファイルを読み込み、内容確認まで進める。同じデータの読み込みはIDで重複を避けて統合します。
- オンラインでアプリを開き、オフライン準備完了の表示を確認してから、機内モードで開き直す。

確認後、テスト用の記録は削除できます。
**この配布版はiPhone実機での動作確認をまだ行っていません。** 実施済みテストと未確認項目は `TESTING.md` に記載しています。

## できること

### 今日
強さ0〜10を選んで、その場の記録を残します。強さの初期値は決めつけません。
きっかけ、場所、続いた時間、その後の状況、したこと、メモは後から追加できます。
「いまは渇望なし」は、その時点での確認です。一日全体を「渇望なし」と断定しません。

### 足あと
月ごとのカレンダーで履歴を見られます。過去の日の追記、編集、削除もできます。
色だけでなく数値や文章で状態を確認できます。未記録の日と、0を記録した日は分けて表示します。

### 気づき
7・14・30・90日間の強さ、回数、時間帯、きっかけなどを振り返れます。
平均の強さは「渇望あり」の記録が分母です。未記録の日を勝手に0に置き換えません。
「その後の強さ」は任意入力で、記録されたペアだけを集計します。
傾向の表示は記述的な集計であり、診断や対処法の効果判定ではありません。

### 相談メモ
診察で話したいことを書き、期間別の集計と一緒に確認できます。
プレビュー、コピー、テキスト共有、テキスト保存、印刷用表示を用意しています。
「印刷／PDF」は端末の印刷画面を利用します。PDF保存の操作や可否は端末の機能に従います。
共有が使えない場合は、テキスト保存またはコピーを利用してください。

各記録の詳しいメモを含めるか選べます。**相談メモ自体は出力に含まれる**ので、共有前にプレビューしてください。
期間は最大366日です。相談メモの未保存変更や無効な日付範囲があると、出力を止めて案内します。

## 少しだけ、特別な仕掛け

**時間で表情が変わる海。**
開いたときの時刻に合わせて朝・昼・夕方・夜の景色を表示します。動きは設定で止められます。

**星の庭。**
記録がある日につき、星がひとつ。強さや服用の有無で星の価値は変わりません。
連続日数を競わせたり、休んだ日を失敗にしたりしません。
庭には直近60日分の記録日の星を描き、累計の記録日数は別に表示します。
星は保存してある記録をもとに描くため、その日の記録をすべて削除すると対応する星も変わります。

**ウェインツ君からの小さな手紙。**
海の小さな星から、日替わりの手紙を開けます。
12通のあらかじめ用意した文章を日付で切り替えています。記録をAIへ送って作る機能ではありません。

**ひと息の部屋。**
30秒・90秒・3分の小さな休憩。静かな波音を任意で鳴らせます。
自分で決めた「お守りの言葉」も表示できます。
薬の服用を遅らせるためのタイマーではありません。
アプリを閉じた後の通知・アラームはなく、戻ったときに経過時間を反映します。音は画面を離れると停止します。

**白い砂浜／夜の海。**
ライト、ダーク、端末に合わせる、の3種類。呼び名や動きの有無も変更できます。

## 記録の言葉について

「我慢できた＝成功」「薬を使った＝失敗」という採点はしていません。
「服用せず過ごした」「処方の範囲内で服用」「処方とは違う使い方」「まだ途中」など、
その後の状況を中立的に残す設計です。

このアプリは個人の記録・相談準備のためのもので、診断、治療、服用量の判断を行いません。
服用や中止・減量は、医師・薬剤師の指示に従ってください。
困ったときに自分で開ける相談先の案内を用意していますが、自動で監視・通報・連絡する機能はありません。

## データをなくさないために

**記録は、その端末・ブラウザの保存領域に置きます。クラウド同期やサーバーバックアップはありません。**

設定 → バックアップで、10文字以上のパスフレーズを指定し、暗号化した `.nagi` ファイルを書き出せます。
暗号化を準備した後、表示された保存リンクをタップして、端末の保存操作を完了してください。
アプリの「書き出し」日時は保存操作を始めた日時です。ファイル保存の完了まではアプリから検証できません。

- パスフレーズはアプリに保存しません。忘れると復号・復旧できません。
- バックアップは安全な保管場所へ。**GitHubへのアップロードはしないでください。**
- 設定・相談メモもバックアップに含みます。読み込みでは記録を統合し、現在の設定は置き換えません。
- 同じIDの記録は更新日時で新しいものを採用します。古いバックアップを戻すと、削除した記録が復活する場合があります。
- アプリ内の全削除は、すでに書き出したファイルまでは削除しません。
- SafariのWebサイトデータ削除、端末の故障・初期化・機種変更、保存容量不足などに備え、定期的に書き出してください。
- 保存の永続化を端末へ依頼するボタンはありますが、許可や永久保存を保証するものではありません。

**端末内の通常の記録は、このアプリ独自の暗号化をしていません。**
暗号化されるのは、パスフレーズを設定して書き出したバックアップです。
画面のプライバシーカバーも、Face IDやパスコード認証ではありません。
詳しい範囲・限界は `PRIVACY.md` をご確認ください。

WebKitの保存ポリシー：
https://webkit.org/blog/14403/updates-to-storage-policy/

## ファイル構成

```text
index.html                 起動ページ
style.css                  画面・印刷レイアウト
app.js                     画面と操作
core.js                    集計・検証・日付処理
storage.js                 端末保存・暗号化バックアップ
sw.js                      オフライン用アプリキャッシュ
manifest.webmanifest       ホーム画面アプリ設定
assets/                    オリジナルアイコン
.nojekyll                  GitHub Pages向け
.gitignore                 Git利用時の誤登録防止補助
README.md                  この説明
PRIVACY.md                 保存・共有・保護の範囲
TESTING.md                 テスト内容と実機確認項目
```

外部CDN、外部フォント、解析タグ、広告、外部AIサービスは使用していません。
アプリの読み込み・更新時には公開先への通信が発生しますが、記録を送信するコードは含みません。

## 更新するとき

最初にバックアップを書き出し、同じ公開先へ新しいアプリ一式を配置してください。
自分でコードを変更して配布する場合、`sw.js` の `VERSION` と `core.js` の `VERSION` を更新します。
新しい版の準備ができるとアプリが案内します。未保存の入力がある状態で自動的に再読み込みはしません。

リポジトリ名・ドメイン・公開フォルダを変更すると、以前の保存先と別扱いになります。
移動前にバックアップを取り、移動先で読み込みます。

## うまく開けないとき

**404になる：** Pagesの公開完了と、公開元の直下に `index.html` があることを確認します。
ZIPファイルしかアップロードしていない場合は、中身を解凍して配置し直します。

**画面が表示されない／保存できない：** 通常のSafariでHTTPSの公開URLを開いているか確認します。
端末の空き容量と、ほかに開いている凪のタブを確認します。
記録がある場合、安易にWebサイトデータを消さず、先にバックアップを試してください。

**アイコン追加後に記録が見えない：** 以前使った同じ環境で開き、バックアップを取り直します。
自動同期を前提にしないでください。

**更新が出ない：** オンラインで開き、入力を保存して閉じてから再度開きます。
古いキャッシュを使用し続ける場合は、公開した `sw.js` のバージョン変更を確認します。

**暗号化保存や共有が使えない：** HTTPSのSafariで試し、端末の保存・共有画面を確認します。
この配布版のiPhone実機確認は未実施です。`TESTING.md` の項目を確認してください。
